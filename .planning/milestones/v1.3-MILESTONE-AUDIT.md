## Tech Debt Inventory

### Warning (pre-publish action recommended)

- **Missing README.md** (`packages/twentythree-skills/`): The `files` whitelist in `package.json` includes `/README.md` but the file does not exist. The npm publish will succeed (npm silently skips missing whitelisted files) but `npmjs.com/package/twentythree-skills` will show an empty package description. Create a minimal README before publishing.

### Info (non-blocking)

- **SKILL.md plain-text resource index**: All 22 resource group topics are listed in the index table as plain text. Agent runtimes that load referenced files (e.g. via `[topic](path)` links) won't auto-navigate to reference files. Impact: agents must infer `reference/video.md` from `video` topic name. Cosmetic — all files exist at the inferable paths.
- **`add` subcommand silently ignored**: `npx twentythree-skills` and `npx twentythree-skills add` behave identically. No user-facing error on unknown subcommands. Impact: `npx twentythree-skills help` returns the same install behavior rather than help text. Not a functional break.
- **Nyquist compliance: all 3 phases PARTIAL**: VALIDATION.md files exist but `nyquist_compliant: false`. The test strategy is manual smoke — appropriate for a static markdown package with no business logic. No automated test framework is warranted unless the installer grows in complexity.
