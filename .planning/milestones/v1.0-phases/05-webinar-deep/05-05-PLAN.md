**poll/list.ts:**
Create `PollList` extending `AuthenticatedCommand`.

- `static description = 'List polls for a webinar'`
- `static enableJsonFlag = true`
- Args: `id` (string, required, description: 'Webinar ID')
- Flags: `...AuthenticatedCommand.baseFlags`, `token` (string, optional, description: 'Webinar token (auto-looked up if omitted)')
- CRITICAL (Pitfall 5): Poll endpoints use `object_id` NOT `live_id`. The positional arg is still the webinar ID, but the API field name is `object_id`.
- In `run()`:
  1. Parse, `printWorkspaceHeader()`
  2. Token auto-lookup for `object_token`: `const objectToken = flags.token ?? await this.fetchWebinarToken(Number(args.id))`
  3. `this.apiClient.GET('/poll/list', { params: { query: { object_id: Number(args.id), object_token: objectToken } } })`
  4. Handle error: `this.error(applyCliTerms(formatApiError(error)), { exit: EXIT_ERROR })`
  5. Extract polls: `const polls: any[] = Array.isArray((data as any)?.data) ? (data as any).data : (data as any)?.data ? [(data as any).data] : []`
  6. Table: `renderTable(['ID', 'Question', 'Open', 'Results Visible'], polls.map(p => [String(p.poll_id ?? ''), applyCliTerms(String(p.question ?? '')), p.open_p ? 'yes' : 'no', p.display_results_p ? 'yes' : 'no']))`
  7. Count line: `chalk.dim(\`\${polls.length} poll\${polls.length === 1 ? '' : 's'}\`)`
  8. JSON: `formatJsonOutput({ ok: true, data: polls, summary: \`\${polls.length} poll(s)\`, breadcrumbs: [{ domain }, { resource: 'poll' }] })`
