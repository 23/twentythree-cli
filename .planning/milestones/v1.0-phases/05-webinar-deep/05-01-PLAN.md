**attachment/list.ts:**
Create command class `WebinarAttachmentList` extending `AuthenticatedCommand`.

- `static description = 'List attachments for a webinar'`
- `static enableJsonFlag = true`
- Args: `id` (string, required, description: 'Webinar ID')
- Flags: `...AuthenticatedCommand.baseFlags`, `token` (string, optional, description: 'Webinar token (auto-looked up if omitted)'), `include-hidden` (boolean, allowNo, optional)
- In `run()`:
  1. Parse args/flags, call `this.printWorkspaceHeader()`
  2. `const webinarId = Number(args.id)`
  3. `const token = flags.token ?? await this.fetchWebinarToken(webinarId)`
  4. Call `this.apiClient.GET('/live/attachment/list', { params: { query: { live_id: webinarId, token, include_hidden_p: parseBoolParam(flags['include-hidden'], undefined) ?? undefined } } })`
  5. Handle error: `this.error(applyCliTerms(formatApiError(error)), { exit: EXIT_ERROR })`
  6. Extract attachments: `const attachments: any[] = (data as any)?.attachments ?? (data as any)?.data ?? []`
  7. JSON mode: return `formatJsonOutput({ ok: true, data: attachments, summary: 'N attachment(s)', breadcrumbs: [{ domain }, { resource: 'webinar', id: args.id }, { resource: 'attachment' }] })`
  8. Table mode: `renderTable(['Filename', 'Size', 'Hidden'], rows)` where rows map each attachment to `[a.filename, a.filesize ?? '', a.hidden_p ? 'yes' : 'no']`
