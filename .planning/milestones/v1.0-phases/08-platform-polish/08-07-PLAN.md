**Check 1: Credentials stored**
- Call `getActiveWorkspace()` in a try/catch
- If returns a domain string, call `getWorkspaceForDomain(domain)` to get the full entry
- PASS condition: `ws !== null && !!ws.bearer_token`
- PASS detail: the domain string
- FAIL detail: `'No workspace configured'` (if no active workspace) or `'No bearer token stored'` (if workspace exists but no token) or `'Error reading credentials'` (if try/catch catches)

**Check 2: Connectivity** (only run if check 1 passed)
- If check 1 failed, push `{ name: 'Connectivity', passed: false, detail: 'Skipped (no credentials)' }`
- Otherwise, use `fetch()` (Node.js built-in) to HEAD the workspace API base URL:
  ```
  const baseUrl = ws!.api_base_url.replace(/\/?$/, '/')
  try {
    const resp = await fetch(baseUrl, { method: 'HEAD', signal: AbortSignal.timeout(10000) })
    checks.push({ name: 'Connectivity', passed: resp.ok || resp.status < 500, detail: domain! })
  } catch (err: any) {
    checks.push({ name: 'Connectivity', passed: false, detail: err.message ?? 'Connection failed' })
  }
  ```

**Check 3: Token valid** (only run if check 2 passed)
- If check 2 failed, push `{ name: 'Token valid', passed: false, detail: 'Skipped (no connectivity)' }`
- Otherwise, create an API client and make a lightweight GET:
  ```
  const apiBaseUrl = baseUrl + 'api/2/'
  const client = createApiClient({ baseUrl: apiBaseUrl, token: ws!.bearer_token })
  const { error } = await client.GET('/photo/list', { params: { query: { size: 1 } } })
  if (error) {
    const status = (error as any)?.status ?? (error as any)?.code ?? 'unknown'
    checks.push({ name: 'Token valid', passed: false, detail: `${status} ${(error as any)?.message ?? 'Unauthorized'}` })
  } else {
    checks.push({ name: 'Token valid', passed: true, detail: 'Authenticated' })
  }
  ```

```typescript
// Handle --agent flag before workspace resolution (D-2)
// Check raw argv since flags haven't been parsed yet at this point
if (process.argv.includes('--agent')) {
  const ctor = this.ctor as any
  const flagDefs = ctor.flags ?? {}
  const agentMeta: AgentMetadata | undefined = ctor.agentMetadata

  // Build flags array from oclif flag definitions
  const flagsArr = Object.entries(flagDefs)
    .filter(([name]) => !['workspace', 'agent', 'json'].includes(name))
    .map(([name, def]: [string, any]) => ({
      name,
      type: def.type ?? 'string',
      required: def.required ?? false,
      default: def.default ?? null,
      description: def.description ?? def.summary ?? '',
    }))

  const output = {
    command: this.id,
    description: ctor.description ?? '',
    flags: flagsArr,
    examples: (ctor.examples ?? []).map((e: any) => typeof e === 'string' ? e : e?.command ?? String(e)),
    api_endpoint: agentMeta?.api_endpoint ?? null,
    auth_scope: agentMeta?.auth_scope ?? 'read',
    output_shape: agentMeta?.output_shape ?? { type: 'none' },
    side_effects: agentMeta?.side_effects ?? 'none',
  }

  process.stdout.write(JSON.stringify(output, null, 2) + '\n')
  process.exit(0)
}
```

This handler:
1. Checks `process.argv.includes('--agent')` before flag parsing (since we're in init())
2. Reads `this.ctor.agentMetadata` (the static field each command declares)
3. Reads `this.ctor.flags` (oclif's built-in flag descriptors)
4. Builds the D-2 JSON output shape
5. Writes to stdout and exits — never reaches workspace resolution or API calls

**Important:** The `process.argv.includes('--agent')` check is used because at this point in init() the flags may not have been parsed yet by oclif. This is the same approach the PATTERNS.md recommends.
