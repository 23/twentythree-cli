- Class `SpotList` extends `AuthenticatedCommand`

- Hidden alt flag: `'active-p': Flags.string({ hidden: true })`
- API call: `this.apiClient.GET('/spot/list', { params: { query: { spot_id: flags['spot-id'], search: flags.search, spot_type: flags['spot-type'], active_p: activeVal !== undefined ? (activeVal ? 1 : 0) : undefined, p: flags.page, size: flags.size, orderby: flags.orderby, order: flags.order } } })`
- Use `parseBoolParam(flags.active, flags['active-p'])` for the active flag

- Dim count: `` `${rows.length} spot(s)` ``
- JSON breadcrumbs: `[{ domain }, { resource: 'spot' }]`
- Add `static agentMetadata = { api_endpoint: 'GET /spot/list', auth_scope: 'read' as const, output_shape: { type: 'table' as const, columns: ['ID', 'Name', 'Type', 'Active'] }, side_effects: 'none' as const }`

**spot/create.ts** (SPT-02) — Pattern B (POST create):
- Class `SpotCreate` extends `AuthenticatedCommand`

- Headers: `{ 'Content-Type': 'application/x-www-form-urlencoded' }`

- agentMetadata: `{ api_endpoint: 'POST /spot/create', auth_scope: 'write', output_shape: { type: 'key-value' }, side_effects: 'creates' }`

**spot/update.ts** (SPT-03) — Pattern D (POST update, flag-only mode):
- Class `SpotUpdate` extends `AuthenticatedCommand`
