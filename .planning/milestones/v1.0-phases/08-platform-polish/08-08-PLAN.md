**Mapping rules:**
- Find `apiClient.GET('/xxx')` or `apiClient.POST('/xxx')` — that's the `api_endpoint`
- GET commands → `side_effects: 'none'`
- POST that creates → `side_effects: 'creates'`
- POST that updates → `side_effects: 'updates'`
- POST that deletes → `side_effects: 'destructive'`
- If file has `renderTable(['Col1', 'Col2', ...])` → `output_shape: { type: 'table', columns: ['Col1', 'Col2', ...] }`
- If file does key-value output → `output_shape: { type: 'key-value' }`
- All video commands → `auth_scope: 'write'` for mutations, `'read'` for GETs

**Expected agentMetadata for key commands (derive the rest by reading each file):**
