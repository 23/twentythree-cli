**Step 2: Create `analytics/video/timeseries.ts`**

- Class: `AnalyticsVideoTimeseries extends AuthenticatedCommand`
- `static description = 'Get video analytics time series data'`
- `static enableJsonFlag = true`
- `static flags = { ...AuthenticatedCommand.baseFlags, ...ANALYTICS_DATE_FLAGS, ...ANALYTICS_FILTER_FLAGS }` (no pagination — timeseries has no p/size per RESEARCH table)
- `run()`: call `this.apiClient.GET('/analytics/data/videos/timeseries', { params: { query: { date_start: flags['date-start'], date_end: flags['date-end'], date_expression: flags['date-expression'], selection: flags.selection, groupby: flags.groupby as any, orderby: flags.orderby, order: flags.order } } })`
- CRITICAL: path must be `/analytics/data/videos/timeseries` (plural `videos`) per Pitfall 2
- Cast response: `const resp = data as any; const rows: unknown[] = Array.isArray(resp?.data) ? resp.data : []`
- JSON output: `formatJsonOutput({ ok: true, data: rows, summary: '${rows.length} row(s)', breadcrumbs: [{ domain: this.activeWorkspace.domain }, { resource: 'analytics' }] })`
- Table output: headers `['Date', 'Plays', 'Engagement', 'Playrate', 'Traffic']`, map rows extracting `date, plays, engagement, playrate, traffic`
- Empty state: `this.log('No data found.')`
- Count line: `this.log(chalk.dim('N rows'))`
- Do NOT apply `applyCliTerms()` to data values — only to error messages per Pitfall 7
