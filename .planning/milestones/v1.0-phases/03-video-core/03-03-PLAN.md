    1. Extend `AuthenticatedCommand`. Args: `file` (required, path to video file). Flags: `--title`, `--description`, `--tags`, `--category-id`, `--publish` (boolean), `--chunk-size` (integer, default 100MB), `--concurrency` (integer, default 5).
    2. Call `this.printWorkspaceHeader()`.
    3. Validate file exists using `fs.stat`. If not found, `this.error(\`File not found: ${args.file}\`, { exit: EXIT_ERROR })`.
    4. Step 1 — Get upload token:
       ```typescript
       const { data: tokenData, error } = await this.apiClient.GET('/photo/get-upload-token', {
         params: { query: {
           title: flags.title,
           description: flags.description,
           tags: flags.tags,
           album_id: flags['category-id'],
           publish: flags.publish ? '1' : undefined,
         } },
       })
       ```
       Extract `upload_token` from response. Error → `this.error(applyCliTerms(...), { exit: EXIT_ERROR })`.
    5. Step 2 — Upload chunks with progress bar:
       ```typescript
       import * as cliProgress from 'cli-progress'
       const totalBytes = (await stat(args.file)).size
       const bar = new cliProgress.SingleBar({
         format: '[{bar}] {percentage}% | {value_fmt} / {total_fmt} | ETA: {eta_formatted} | {speed}',
         barCompleteChar: '\u2588', barIncompleteChar: '\u2591',
         hideCursor: true, clearOnComplete: true,
       }, cliProgress.Presets.shades_classic)
       bar.start(totalBytes, 0, { value_fmt: '0 B', total_fmt: formatBytes(totalBytes), speed: 'N/A' })

       const startTime = Date.now()
       const result = await uploadChunked({
         filePath: args.file,
         uploadToken: tokenData.upload_token,
         uploadUrl: `${this.activeWorkspace.api_base_url}photo/redeem-upload-token`,
         chunkSize: flags['chunk-size'],
         concurrency: flags.concurrency,
         onProgress(bytesUploaded, total) {
           const elapsed = (Date.now() - startTime) / 1000
           const speed = elapsed > 0 ? bytesUploaded / elapsed : 0
           bar.update(bytesUploaded, {
             value_fmt: formatBytes(bytesUploaded),
             total_fmt: formatBytes(total),
             speed: `${formatBytes(speed)}/s`,
           })
         },
       })
       bar.stop()
       ```
    6. Log success: `this.log(chalk.green('Video uploaded successfully'))`.
    7. If `--json`, return `formatJsonOutput({ data: result, summary: 'Video uploaded', breadcrumbs: [{ domain: this.activeWorkspace.domain }, { resource: 'video', id: String(result.photo_id) }] })`.

       const body: Record<string, unknown> = { photo_id: Number(args.id) }

    6. POST to `/photo/update` with form-encoded body.
