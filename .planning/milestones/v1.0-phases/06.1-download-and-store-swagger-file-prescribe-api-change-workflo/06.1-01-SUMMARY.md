## What Changed

### packages/twentythree-cli/specs/twentythree-api-swagger.json
New file — 2.75 MB local copy of the TwentyThree OpenAPI spec downloaded from `https://video.twentythree.com/apidocs/swagger.json`. Committed to the repo so `generate-types` works offline and spec changes are tracked in git history.

### packages/twentythree-cli/update-api-spec.sh
New executable shell script implementing the download-diff-regenerate workflow:
1. `curl -sSf` downloads latest spec to local file
2. `git ls-files --error-unmatch` detects first-run vs subsequent run (handles Pitfall 2)
3. `git diff specs/twentythree-api-swagger.json || true` shows changes (handles Pitfall 4: exit code 1)
4. `BASH_SOURCE[0]` anchors all paths to the script directory (handles Pitfall 1)
5. Calls `pnpm generate-types` to regenerate types

### package.json (root)
- `generate-types` script updated from remote URL to local file path (`specs/twentythree-api-swagger.json`)
- New `update-api-spec` script alias added: `cd packages/twentythree-cli && ./update-api-spec.sh`

### CLAUDE.md
New `## API Change Workflow` section appended after `<!-- GSD:profile-end -->`. Contains all five D-4 items: how to run the script, what the diff means, how to use Claude Code, verification steps, and commit instructions. Notes pre-existing tsc errors caveat.
