    Three sub-steps, all per locked decisions D-1, D-2, D-3:

    **Step A — Download and store the spec (D-1):**
    1. Create directory `packages/twentythree-cli/specs/`
    2. Download `https://video.twentythree.com/apidocs/swagger.json` to `packages/twentythree-cli/specs/twentythree-api-swagger.json` using curl
    3. Verify the downloaded file is valid JSON (e.g., `node -e "JSON.parse(require('fs').readFileSync('packages/twentythree-cli/specs/twentythree-api-swagger.json','utf8'))"`)

    **Step B — Create the shell script (D-3):**
    Write `packages/twentythree-cli/update-api-spec.sh` with this exact content:

    ```bash
    #!/usr/bin/env bash
    set -euo pipefail

    SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    SPEC_FILE="$SCRIPT_DIR/specs/twentythree-api-swagger.json"
    SPEC_URL="https://video.twentythree.com/apidocs/swagger.json"

    mkdir -p "$SCRIPT_DIR/specs"

    echo "Downloading TwentyThree API spec..."
    curl -sSf "$SPEC_URL" -o "$SPEC_FILE"

    echo ""
    echo "=== Changes ==="
    if git -C "$SCRIPT_DIR" ls-files --error-unmatch "specs/twentythree-api-swagger.json" 2>/dev/null; then
      git -C "$SCRIPT_DIR" diff specs/twentythree-api-swagger.json || true
    else
      echo "New spec file — no previous version to diff"
    fi

    echo ""
    echo "Regenerating types..."
    cd "$(git -C "$SCRIPT_DIR" rev-parse --show-toplevel)"
    pnpm generate-types

    echo ""
    echo "Done. If the diff shows API changes:"
    echo "  1. Run: pnpm --filter twentythree-cli exec tsc --noEmit"
    echo "  2. Paste the diff + any TypeScript errors into Claude Code"
    echo "  3. Follow CLAUDE.md § 'API Change Workflow'"
    ```

    Then run `chmod +x packages/twentythree-cli/update-api-spec.sh`.

    **Step C — Update root package.json scripts (D-1, D-3):**
    1. Change `generate-types` value from:
       `pnpm --filter twentythree-cli exec openapi-typescript https://video.twentythree.com/apidocs/swagger.json -o src/api/types.ts`
       to:
       `pnpm --filter twentythree-cli exec openapi-typescript specs/twentythree-api-swagger.json -o src/api/types.ts`
    2. Add new script `update-api-spec` with value:
       `cd packages/twentythree-cli && ./update-api-spec.sh`

    **What NOT to do:**
    - Do NOT use `wget` (not default on macOS) — use `curl -sSf` (Pitfall 3)
    - Do NOT use relative paths without `$SCRIPT_DIR` anchoring in the shell script (Pitfall 1)
    - Do NOT omit `|| true` after `git diff` — exit code 1 means "differences found" and would abort the script under `set -e` (Pitfall 4)
    - Do NOT create a README — CLAUDE.md is the documentation target (D-4)
  </action>
