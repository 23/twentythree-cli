**Change 2 — PKG-02 prepack script (per D-06):**
Add `"prepack": "pnpm build"` to the `scripts` object. Place it after `"postbuild": "oclif manifest"` and before `"dev": "node ./bin/dev.js"`. The final scripts block:

```json
"scripts": {
  "audit-endpoints": "node scripts/audit-endpoints.mjs",
  "build": "tsdown --config-loader unrun",
  "postbuild": "oclif manifest",
  "prepack": "pnpm build",
  "dev": "node ./bin/dev.js",
  "test": "vitest run"
}
```

Do NOT use `prepare` (fires on consumer install) or `prepublishOnly` (does not fire on npm pack). Must be `prepack`.

**Change 3 — PKG-03 files array (per D-07, D-08):**
Add `/docs` and `/README.md` to the `files` array. Final array:

```json
"files": [
  "/bin",
  "/dist",
  "/oclif.manifest.json",
  "/docs",
  "/README.md"
]
```

Use leading `/` to match existing anchor convention.

**Do NOT change:**
- `version` — must remain `"0.1.0"` (per D-09, Phase 13 owns version bump)
- `build`, `postbuild`, or any other existing script
- `oclif`, `dependencies`, `devDependencies` sections
- `name`, `description`, `license`, `type`, `engines`, `bin`, `main`
