```typescript
// BaseCommand is abstract and generic. Subclasses must provide the generic type
// argument (pattern from the rest of the codebase: `extends BaseCommand<typeof ClassName>`).
export abstract class BaseCommand<T extends typeof Command> extends Command {
  static enableJsonFlag = true
  static baseFlags = { workspace, agent }
  public async init(): Promise<void> // resolves --workspace, --agent, bearer token
  public async catch(err): Promise<void> // intercepts FailedFlagValidationError, prompts interactively
  protected printWorkspaceHeader(): void
}
```

Important: `BaseCommand.init()` will resolve a workspace and call `this.error()` if none is configured. The `autocomplete` command must run in a workspace-less environment (first-time setup). Workaround options for Task 2:
  - A. Override `init()` in `Autocomplete` to skip super.init() entirely (simplest; preserves "no auth required" for autocomplete)
  - B. Skip BaseCommand and keep bare Command

Per v1.2-MILESTONE-AUDIT.md fix recommendation and this plan's success criteria, Option A is required: `Autocomplete` MUST extend `BaseCommand` and override `init()` to bypass the workspace resolution (autocomplete runs before auth is configured).
