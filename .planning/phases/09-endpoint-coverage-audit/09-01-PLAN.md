**1. Create `scripts/audit-endpoints.mjs`** (per D-05, D-06, D-07):

Create a `scripts/` directory at `packages/twentythree-cli/scripts/`. The script is a Node.js ES module (`.mjs`).

Structure:
```javascript
#!/usr/bin/env node
import { readFileSync, readdirSync, statSync } from 'node:fs'
import { resolve, dirname, join, extname } from 'node:path'
import { fileURLToPath } from 'node:url'

const __dirname = dirname(fileURLToPath(import.meta.url))
```

**Step A: Extract spec endpoints.** Read `../specs/twentythree-api-swagger.json`, parse JSON, iterate `spec.paths`. For each path key, iterate methods `['get', 'post', 'put', 'patch', 'delete']`. If `methods[method]` exists, add `"${method.toUpperCase()} ${pathKey}"` to a `Set` called `specEndpoints`.

**Step B: Extract command api_endpoint values.** Recursively walk `../src/commands/` for `.ts` files. For each file, `readFileSync(filePath, 'utf8')` and apply regex `/api_endpoint:\s*'([^']+)'/g`. Collect all matches into a `Set` called `cmdEndpoints`. Use a recursive `walkDir(dir)` function that calls `readdirSync` + `statSync` to traverse directories.

**Step C: Parse EXCLUDED_OPERATIONS from source.** Read `../src/lib/audit.ts` as text. Apply regex `/endpoint:\s*'([^']+)'/g` to extract all endpoint strings into a `Set` called `excludedEndpoints`. This avoids needing `tsx` -- pure regex on the TypeScript source.

**Step D: Define KNOWN_NON_API.** Hardcode: `const KNOWN_NON_API = new Set(['interactive', 'local'])`. These are sentinel `api_endpoint` values from CLI-only commands (auth/credentials, auth/status, workspace/use, workspace/list).

**Step E: Compute gaps and phantoms.**
- `gaps`: spec endpoints NOT in cmdEndpoints AND NOT in excludedEndpoints
- `phantoms`: cmd endpoints NOT in specEndpoints AND NOT in KNOWN_NON_API AND NOT in excludedEndpoints

**Step F: Output.** Print in this format:
```
=== Endpoint Coverage Audit ===

Spec endpoints:  235
Cmd endpoints:   215
Excluded:        8
Known non-API:   2

Covered:         XXX
Gaps:            XX
Phantoms:        XX

[If gaps > 0:]
--- Gaps (spec endpoints with no command and not excluded) ---
  GET /analytics/data/live/weekday/timeseries
  ...

[If phantoms > 0:]
--- Phantoms (command api_endpoint values not in spec) ---
  POST /photo/frame  (src/commands/video/frame.ts)
  ...

[If gaps === 0 && phantoms === 0:]
All endpoints covered or excluded. Audit passed.
```

For phantom output, also print the source file path. When walking commands in Step B, store a `Map<string, string[]>` of `endpoint -> [filePaths]` so the phantom report can show which file declares the phantom endpoint.

**Step G: Exit code.** `process.exit(gaps.length > 0 || phantoms.length > 0 ? 1 : 0)` per D-06.
