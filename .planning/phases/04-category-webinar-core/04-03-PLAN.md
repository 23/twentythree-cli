<objective>
Extend the chunked upload engine with extraFields support and implement the webinar upload-image command using it.

Purpose: The webinar upload-image endpoint requires `type` (thumbnail/preview/before_webinar) as an extra form field alongside the resumable.js params. The current engine only supports tokenFieldName. This plan adds the generic extraFields capability and builds the upload-image command on top of it.

Output: Modified upload types and engine, new upload-image command, updated engine tests, new command test.
</objective>
