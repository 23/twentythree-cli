Create action/upload.ts implementing D-1: simple multipart FormData POST via native fetch. No chunked engine, no openapi-fetch for this endpoint.

**action/upload.ts (ACT-09):**
- Args: `id` (string, required -- action_id), `variable-name` (string, required), `file` (string, required -- file path).
- No special flags beyond baseFlags.
- Steps:
  1. Validate file exists using `stat(args.file)` -- error with `EXIT_ERROR` if not found.
  2. Read file: `const fileBuffer = await readFile(args.file)`.
  3. Build FormData:
     ```
     const formData = new FormData()
     formData.append('action_id', String(Number(args.id)))
     formData.append('variable_name', args['variable-name'])
     formData.append('file', new Blob([fileBuffer]), basename(args.file))
     ```
  4. Build headers: `Authorization: Bearer ${token}` only if token exists.
  5. POST via native `fetch(`${this.apiBaseUrl}action/upload`, { method: 'POST', headers, body: formData })`.
  6. Check `response.ok` -- if not, read body text and error with `applyCliTerms(...)`.
  7. Parse JSON response: `const json = await response.json()`.
  8. Success: `chalk.green('File uploaded to action variable')`.
  9. JSON mode: `formatJsonOutput({ ok: true, data: json, summary: 'File uploaded', breadcrumbs })`.

Import `readFile` from `node:fs/promises`, `stat` from `node:fs/promises`, `basename` from `node:path`.

Do NOT use the chunked upload engine. Do NOT use openapi-fetch for this endpoint. Per D-1, this is a simple one-shot multipart POST.
  </action>
