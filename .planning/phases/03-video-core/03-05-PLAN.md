    All subtitle commands extend `AuthenticatedCommand`, call `this.printWorkspaceHeader()`, support `--json`, and apply `applyCliTerms`. Follow the same patterns as section commands from Plan 04.

    **subtitle list** (`src/commands/video/subtitle/list.ts`):
    1. Args: `id` (required, video ID).
    2. `GET /photo/subtitle/list` with `{ params: { query: { photo_id: args.id } } }`.
    3. Render table: ID, Locale, Type, Status (draft/published), Primary.
    4. If `--json`, return formatJsonOutput.

    **subtitle create** (`src/commands/video/subtitle/create.ts`):
    1. Args: `id` (required, video ID). Flags: `--locale` (required, e.g. "en_US" or "auto"), `--type` (optional, default "general"), `--draft` (boolean, optional).
    2. `POST /photo/subtitle/create` with form-encoded body: `{ photo_id, locale, type, draft_p }`.
    3. Log success, return formatJsonOutput.

    **subtitle update** (`src/commands/video/subtitle/update.ts`):
    1. Args: `id` (required, video ID). Flags: `--subtitle-id` (required), `--locale`, `--type`, `--draft` (all optional — only send provided).
    2. `POST /photo/subtitle/update` with form-encoded body including only provided fields.

    **subtitle delete** (`src/commands/video/subtitle/delete.ts`):
    1. Args: `id` (required, video ID). Flags: `--subtitle-id` (required).
    2. Confirmation prompt including workspace domain.
    3. `POST /photo/subtitle/remove` with `{ photo_id, subtitle_id }`. Note: API endpoint is `/remove`, not `/delete`.
    4. If `--json`, skip confirmation.

    **subtitle upload** (`src/commands/video/subtitle/upload.ts`):
    1. Args: `id` (required, video ID), `file` (required, path to SRT/WebVTT file). Flags: `--locale` (required), `--type` (optional), `--draft` (boolean).
    2. Validate file exists.
    3. Read the file into a Buffer, create a Blob.
    4. Use `this.apiClient.POST('/photo/subtitle/upload', { body: { photo_id, file: fileBlob, locale, type, draft_p }, bodySerializer(body) { const fd = new FormData(); for (const [k, v] of Object.entries(body)) { if (v !== undefined) fd.append(k, v as string | Blob) }; return fd } })`.
    5. This is a direct multipart POST — NOT the chunked upload engine (subtitle files are small).
    6. Log success, return formatJsonOutput.
  </action>
