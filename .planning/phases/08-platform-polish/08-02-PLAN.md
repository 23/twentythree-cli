**webhook/list.ts** (WHK-01) — Pattern A (GET list):
- Class `WebhookList` extends `AuthenticatedCommand`
- GET `/webhook/list` — no required params
- Table columns: `['ID', 'Event', 'Target URL']` mapped from `[webhook_id, event, target_url]`
- Empty state: `'No webhooks found.'`
- agentMetadata: `{ api_endpoint: 'GET /webhook/list', auth_scope: 'read', output_shape: { type: 'table', columns: ['ID', 'Event', 'Target URL'] }, side_effects: 'none' }`

**webhook/subscribe.ts** (WHK-02) — Pattern B (POST create):
- Class `WebhookSubscribe` extends `AuthenticatedCommand`
- Flags: `'target-url'` (string, required: true), `event` (string, required: true)
- POST `/webhook/subscribe` with body `{ target_url: flags['target-url'], event: flags.event } as any`
- Headers: `{ 'Content-Type': 'application/x-www-form-urlencoded' }`
- Success: `chalk.green('Webhook subscription created')`
- Extract `webhook_id` from `(data as any)?.data?.webhook_id`
- agentMetadata: `{ api_endpoint: 'POST /webhook/subscribe', auth_scope: 'write', output_shape: { type: 'key-value' }, side_effects: 'creates' }`

**webhook/unsubscribe.ts** (WHK-03) — Pattern C (POST destructive with confirmation):
- Class `WebhookUnsubscribe` extends `AuthenticatedCommand`
- Flags: `'webhook-id'` (string, description: 'Webhook subscription ID'), `'target-url'` (string, description: 'Target URL to unsubscribe')
- Validation: at least one of `--webhook-id` or `--target-url` must be provided. If neither: `this.error('Provide --webhook-id or --target-url', { exit: EXIT_ERROR })`
- Confirmation: `Unsubscribe webhook from ${this.activeWorkspace.domain}? This cannot be undone.`
- POST `/webhook/unsubscribe` with body: `{ webhook_id: flags['webhook-id'] ? Number(flags['webhook-id']) : undefined, target_url: flags['target-url'] } as any`
- agentMetadata: `{ api_endpoint: 'POST /webhook/unsubscribe', auth_scope: 'write', output_shape: { type: 'key-value' }, side_effects: 'destructive' }`

**webhook/events.ts** (WHK-04) — Pattern A variant (GET list, simple string items):
- Class `WebhookEvents` extends `AuthenticatedCommand`
- Flags: `'test-authentication'` (boolean, description: 'Include test authentication events'), `'test-authentication-p'` (string, hidden)
- GET `/webhook/events` with `params: { query: { test_authentication_p: testAuthVal !== undefined ? (testAuthVal ? 1 : 0) : undefined } }`
- Use `parseBoolParam` for test-authentication
- Output: Table with single column `['Event']` — each row is `[String(item.event ?? item)]`
- agentMetadata: `{ api_endpoint: 'GET /webhook/events', auth_scope: 'read', output_shape: { type: 'table', columns: ['Event'] }, side_effects: 'none' }`

**webhook/sample.ts** (WHK-05) — Pattern E variant (GET single, raw JSON output):
- Class `WebhookSample` extends `AuthenticatedCommand`
- Args: `event` (string, required, description: 'Event type to get sample for')
- GET `/webhook/sample` with `params: { query: { event: args.event } }`
- Non-JSON output: `this.log(JSON.stringify((resp?.data ?? resp), null, 2))` — sample payloads are complex nested JSON, not suitable for key-value render
- JSON output wraps in standard envelope
- agentMetadata: `{ api_endpoint: 'GET /webhook/sample', auth_scope: 'read', output_shape: { type: 'key-value' }, side_effects: 'none' }`
