**presentation/setting/update.ts** (PRS-02) — Pattern D variant (POST freeform key-value, Pitfall 4):
- Class `PresentationSettingUpdate` extends `AuthenticatedCommand`
- Flags: `set` (string, `multiple: true`, description: 'Setting key=value pair (repeatable)')
- Validation: `if (!flags.set || flags.set.length === 0) this.error('Provide at least one --set key=value pair', { exit: EXIT_ERROR })`
- Build body by parsing --set pairs:
  ```
  const body: Record<string, unknown> = {}
  for (const pair of flags.set) {
    const idx = pair.indexOf('=')
    if (idx < 1) this.error(`Invalid --set value: "${pair}" (expected key=value)`, { exit: EXIT_ERROR })
    body[pair.slice(0, idx)] = pair.slice(idx + 1)
  }
  ```
- POST `/presentation/setting/update` with `body: body as any`
- Headers: `{ 'Content-Type': 'application/x-www-form-urlencoded' }`
- Success: `chalk.green('Presentation settings updated')`
- agentMetadata: `{ api_endpoint: 'POST /presentation/setting/update', auth_scope: 'write', output_shape: { type: 'key-value' }, side_effects: 'updates' }`
