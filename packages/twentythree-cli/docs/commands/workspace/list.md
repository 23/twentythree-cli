## `twentythree workspace list`

List all configured workspaces

```
USAGE
  $ twentythree workspace list [--json] [-w <value>]

GLOBAL FLAGS
  -w, --workspace=<value>  Workspace domain or display name to use for this invocation.
      --json               Format output as json.

DESCRIPTION
  List all configured workspaces

EXAMPLES
  $ twentythree workspace list
```
